Redpoint - read selected text word by word

1. Run Redpoint.exe. It stays in the background (icon in the tray, near the clock).
   Windows SmartScreen may warn about an unknown publisher: choose "More info" -> "Run anyway".
2. Select text in any program and press Ctrl+Alt+Space.
3. Space pauses, Up/Down change the speed, Left/Right jump by sentence, Esc closes.

Settings (shortcut, speed, font size, start with Windows): click the tray icon.
Your previous clipboard content is restored after the selection is copied.
Source code and help: https://github.com/DawidKrynski/redpoint-reader
